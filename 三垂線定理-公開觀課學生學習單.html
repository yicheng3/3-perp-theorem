一、重點核心：三垂線定理（直觀架構：條件一 ＋ 條件二 $\implies$ 結論） 課本第 132 頁
條件一：線面垂直

$\overline{AB} \perp$ 平面 $E$

（立柱垂直地面於 $B$）
＋
條件二：平面線線垂直

$\overline{BC} \perp$ 直線 $L$

（地面折線垂直 $L$ 於 $C$）
＝
三垂線定理結論

$\overline{AC} \perp$ 直線 $L$

（空間斜線垂直直線 $L$）
二、教師示範：【例題 4】標準空間距離計算（課本第 133 頁） 例題精讀

【題目】如圖所示，設直線 $AB$ 垂直平面 $E$ 於 $B$ 點，平面 $E$ 上有一條直線 $L$。若從 $B$ 點向直線 $L$ 作垂線，垂足為 $C$，且在直線 $L$ 上取一點 $D$。已知 $\overline{AB} = 5$，$\overline{BC} = 4$，$\overline{CD} = 3$，試求空間距離 $\overline{AD}$。

【步驟一：猜猜哪個是直角】 猜猜看空間中哪一個角是直角？
$\angle$ ACD $= 90^\circ$
【步驟二：三垂線定理垂直證明填空】（請依定理架構填入條件與結論）

因為 $\overline{AB} \perp$ 平面 $E$（條件一：線面垂直）， 且 $\overline{BC} \perp$ 直線 $L$（條件二：平面線線垂直），

由三垂線定理可知：空間斜線 $\overline{AC}$ $\perp$ 直線 $L$。 故在直線 $L$ 上，$\angle ACD = $ $90^\circ$。

【步驟三：抽離平面直角三角形，畢氏定理自主計算邊長】
① 立面直角 $\triangle ABC$（求過渡邊 $\overline{AC}$） 直角 $\angle B = 90^\circ$
由畢氏定理：$\overline{AC}^2 = \overline{AB}^2 + \overline{BC}^2$
代入數值：$\overline{AC} = \sqrt{5^2 + 4^2} = \sqrt{25 + 16} = \sqrt{41}$
求得過渡邊：$\overline{AC} = $ $\sqrt{41}$
② 斜面直角 $\triangle ACD$（求目標邊 $\overline{AD}$） 三垂線：$\angle C = 90^\circ$
由畢氏定理：$\overline{AD}^2 = \overline{AC}^2 + \overline{CD}^2$
代入數值：$\overline{AD} = \sqrt{(\sqrt{41})^2 + 3^2} = \sqrt{41 + 9} = \sqrt{50} = 5\sqrt{2}$
求得目標邊：$\overline{AD} = $ $5\sqrt{2}$
【本題課本解答】：空間線段 $\overline{AD} = $ $5\sqrt{2}$

三、隨堂實作：【類題 4】反求立柱高度（課本第 133 頁第 4 題） 學生自主實作

【題目】如圖，設直線 $OA \perp$ 平面 $E$ 於 $A$ 點，平面 $E$ 上有一條直線 $L$。從垂足 $A$ 點向直線 $L$ 作垂線，垂足為 $B$，並在直線 $L$ 上取一點 $C$。若已知 $\overline{AB} = 4$，$\overline{BC} = 12$，空間斜線 $\overline{OC} = 13$，試反求立柱高度 $\overline{OA}$。

【步驟一：猜猜哪個是直角】 猜猜看空間中哪一個角是直角？
$\angle$ OBC $= 90^\circ$
【步驟二：三垂線定理】 因為 $\overline{OA} \perp E$ 且 $\overline{AB} \perp L \implies$ 空間斜線 $\overline{OB}$ $\perp$ 直線 $L$。
【步驟三：抽離平面直角三角形，畢氏定理自主計算邊長】
① 在直角 $\triangle OBC$ 中（求股長 $\overline{OB}$） 斜面直角
$\overline{OB} = \sqrt{13^2 - 12^2} = \sqrt{169 - 144} = 5$
求得中間邊：$\overline{OB} = $ 5
② 在直角 $\triangle OAB$ 中（求立柱高 $\overline{OA}$） 立面直角
$\overline{OA} = \sqrt{5^2 - 4^2} = \sqrt{25 - 16} = 3$
求得立柱高度：$\overline{OA} = $ 3
【本題課本解答】：立柱長度 $\overline{OA} = $ 3
四、生活素養應用：【例 5】平台型鋼琴頂蓋支撐桿（課本第 134 頁） 生活情境數學建模

【題目】如圖是一架平台型鋼琴的抽象幾何模型，$\overline{AB}$ 為支撐架，掀開頂蓋時 $\overline{AB}$ 垂直頂蓋平面於 $B$ 點，而位於頂蓋邊緣的 $C$、$D$ 兩點為鋼琴鉸鍊的鎖孔。已知 $\overline{BC} \perp \overline{CD}$，且 $\overline{AB} = 4$，$\overline{BC} = 4$，$\overline{CD} = 2$，試求空間距離 $\overline{AD}$。

【步驟一：猜猜哪個是直角】 猜猜看空間中哪一個角是直角？
$\angle$ ACD $= 90^\circ$
【步驟二：三垂線定理】 因為 $\overline{AB} \perp$ 頂蓋平面且 $\overline{BC} \perp \overline{CD} \implies \overline{AC} \perp$ $\overline{CD}$。
【步驟三：抽離直角三角形，兩次畢氏定理自主計算】
① 在直角 $\triangle ABC$ 中（求過渡邊 $\overline{AC}$） $\angle B = 90^\circ$
$\overline{AC} = \sqrt{4^2 + 4^2} = \sqrt{32} = 4\sqrt{2}$
求得過渡邊：$\overline{AC} = $ $4\sqrt{2}$
② 在直角 $\triangle ACD$ 中（求目標邊 $\overline{AD}$） $\angle C = 90^\circ$
$\overline{AD} = \sqrt{(4\sqrt{2})^2 + 2^2} = \sqrt{32 + 4} = 6$
求得目標邊：$\overline{AD} = $ 6
【本題課本解答】：空間長度 $\overline{AD} = $ 6
