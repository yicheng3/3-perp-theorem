# 三垂線定理・公開觀課教學系統
### 3D 空間幾何互動探究儀 & JIS B4 雙面學生學習單

專為技術型高中（高職）數學 C「空間概念與三垂線定理」單元設計之公開觀課完整教學解決方案。結合純前端免安裝的 3D 空間透視探究工具與嚴格防溢頁的 B4 油印高對比紙本學習單。

---

## 🌟 專案特色

### 1. 3D 空間幾何互動探究儀 (`index.html` / `三垂線定理互動探究儀.html`)
- **零依賴・純前端原生架構**：採用 HTML5 Canvas + Tailwind CSS + KaTeX 引擎，無大型 3D 庫負擔，大屏觸控、iPad、筆電秒開。
- **全視角 360° 自由拖曳**：隨時旋轉視角破除 2D 黑板透視盲點，並提供快速「俯視角度」與「側視角度」復位。
- **結構化 5 大教學進程**：
  1. **前導：空間透視**：線框與實體對比，引導觀察空間中的線面交角。
  2. **0. 猜測這兩條線有垂直嗎**：精選 11 道強烈認知衝突題型（正方體、長方體、直角三稜柱、四角錐、歪斜線），提供直觀投票與嚴謹幾何解析。
  3. **1. 三垂線定理敘述**：將課本定理降維定錨為「三步定位法」（鉛直下落 $\rightarrow$ 地面出發 $\rightarrow$ 空間連線）。
  4. **2. 練習證明**：課本與經典立體模型（例 4、類題 4、例 5、長方體、面對角線、四角錐）動態填空推導。
  5. **3. 距離計算**：將空間距離計算拆解為「底面直角三角形」與「立體直角三角形」兩步驟畢氏定理，清晰直觀。

### 2. JIS B4 雙面學生學習單 (`三垂線定理-公開觀課學生學習單.html`)
- **雙面嚴格鎖定 2 頁**：針對台灣各校黑白影印機/油印機高對比度印製設計，絕對零溢頁。
- **手腦並用作圖區**：包含三步定位畫圖填空、課本例題 4 與自我挑戰例題 5（標準抽象幾何圖形）。
- **頂部一鍵開啟**：在探究儀右上角設有「學生學習單 (B4)」快捷連結，可直接開啟列印。

## 🚀 快速開始

### 1. 本地直接使用
直接以 Google Chrome、Edge 或 Safari 等現代瀏覽器雙擊開啟 `index.html` 或 `三垂線定理互動探究儀.html` 即可使用，無需架設本地伺服器。

### 2. 學習單列印建議
以瀏覽器開啟 `三垂線定理-公開觀課學生學習單.html`，按下 `Ctrl + P`（Mac 為 `Cmd + P`）：
- 紙張大小：選擇 **B4 (JIS)**
- 邊界：選擇 **無 (None)**
- 列印選項：勾選 **背景圖形**
- 正反雙面列印即可直接發放。

## 🌐 啟用 GitHub Pages 線上版

將此儲存庫推送至 GitHub 後，可一鍵開啟免費線上網址供公開觀課課堂投影或學生平板使用：

1. 進入 GitHub 儲存庫頁面。
2. 點擊頂部的 **Settings** $\rightarrow$ 左側選單 **Pages**。
3. 在 **Build and deployment** 下的 **Branch** 選擇 `main` 分支，資料夾選擇 `/ (root)`，點擊 **Save**。
4. 等待 1~2 分鐘，即可獲得線上訪問網址：
   ```text
   https://<你的GitHub帳號>.github.io/<儲存庫名稱>/
   ```
